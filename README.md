# Visualizador do Algoritmo de Dijkstra

Aplicação interativa desenvolvida para a disciplina de **Algoritmos e Estrutura de Dados II** do curso de **Engenharia de Software** da **UniAlfa**. O projeto tem como objetivo demonstrar visualmente o funcionamento do **Algoritmo de Dijkstra** na busca pelo caminho mais curto em grafos ponderados.

---

## Sobre o Projeto

O sistema foi criado para facilitar a compreensão dos conceitos teóricos estudados em sala de aula através de uma interface gráfica intuitiva ("telinha"). *Nota de desenvolvimento: Ferramentas de Inteligência Artificial foram utilizadas como suporte e apoio durante o processo de desenvolvimento da aplicação.*

---

## Funcionalidades

* **Interface Gráfica Interativa:** Permite visualizar e interagir com a estrutura do grafo de forma amigável.
* **Execução do Dijkstra:** Demonstração prática e visual do cálculo das menores distâncias entre os nós.
* **Manipulação de Grafos:** Visualização clara de vértices, arestas e seus respectivos pesos.

---

## Tecnologias Utilizadas

* **Linguagem:** JavaScript/React
* **Interface Gráfica (GUI):** React
* **Estruturas de Dados:** Grafos, Listas de Adjacência, Filas de Prioridade (Heap).

---

## Pré-requisitos

Certifique-se de ter instalado em sua máquina:
* Node.js

---

## Como Executar

1. **Clone este repositório:**
   ```bash
   git clone [https://github.com/Execatsu/Facul-GrafosDijkstra.git](https://github.com/Execatsu/Facul-GrafosDijkstra.git)
   ```
2. **Acesse a pasta do projeto:**
   ```bash
   cd Facul-GrafosDijkstra
   ```
3. **Instale as dependências:**
   ```bash
   npm install
   ```
4. Execute a aplicação:
   ```bash
   npm run
   ```
